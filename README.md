# 🏥 Docpay - Telemedicine Payment Escrow

> 💊 Secure escrow payments for telemedicine consultations - Release funds only after consultation completion

## 🌟 Overview

Docpay is a smart contract-based escrow system for telemedicine payments built on the Stacks blockchain. It ensures secure transactions between patients and doctors by holding payments in escrow until consultations are completed.

## ✨ Features

- 🔒 **Secure Escrow**: Payments held safely until consultation completion
- 👨‍⚕️ **Doctor Verification**: Built-in doctor verification system
- 📅 **Consultation Management**: Complete lifecycle management from booking to completion
- ⭐ **Review System**: Mutual rating and review system for quality assurance
- 💰 **Automatic Fee Distribution**: Platform fees automatically calculated and distributed
- 🚫 **Cancellation Protection**: Fair cancellation policies for both parties
